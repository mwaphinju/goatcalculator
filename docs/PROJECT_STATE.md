## `NEXT_PUBLIC_SITE_URL` (`src/lib/siteConfig.ts`)

`siteConfig.url` is resolved once, validated:

- Unset: falls back to `http://localhost:3000`; `siteConfig.isUrlConfigured`
  is `false`. This is a safe default a build can always run with, and is
  never mistaken for a real, live domain.
- Set to an absolute `https://` URL (any host), or an `http://localhost`
  / `http://127.0.0.1` URL (local development / pre-deployment testing):
  accepted, trailing slash stripped, `isUrlConfigured` is `true`.
- Set to anything else (not an absolute URL, or a non-localhost `http://`
  URL): throws at build time, so a typo or an insecure production value
  fails the build rather than shipping quietly wrong metadata.

Every absolute URL in the app (canonical links, Open Graph URLs,
`sitemap.xml` entries, robots.txt's `Sitemap:` line, and every structured
data `url` field) is built through one function, `absoluteUrl(path)`,
which prepends `siteConfig.url`. There is no second place that could drift
out of sync. **Phase 6 must set `NEXT_PUBLIC_SITE_URL` to the final
Render URL or custom domain before deploying** — see
`docs/SEO_LAUNCH_CHECKLIST.md` and `.env.example`.

## Metadata, robots, sitemap, and structured data

- Every one of the 16 public pages above has a unique `<title>`, a unique
  meta description, a canonical link, Open Graph title/description/url/
  site name, a Twitter `summary` card (title/description only, no
  image), and `robots: index, follow` (set once in the root layout,
  inherited by every page).
- `src/app/robots.ts` and `src/app/sitemap.ts` are Next.js metadata
  routes (`export const dynamic = "force-static"`, required for static
  export) built from `PUBLIC_ROUTES` (`src/lib/routes.ts`), the single
  route list also cross-checked in a vitest test against the actual
  `page.tsx` files on disk, so an added or removed route cannot silently
  drift out of the sitemap.
- Structured data (`src/lib/structuredData.ts`, rendered via
  `src/components/shared/JsonLd.tsx`): `WebSite` on the home page;
  `WebApplication` (name, description, url, `applicationCategory:
  "FinanceApplication"`, `browserRequirements`, `offers.price: "0"`) on
  every calculator page; `BreadcrumbList` on every calculator and guide
  page, built from the exact same items passed to the visible
  `<Breadcrumbs>` component, so the structured data can never claim a
  path the visitor doesn't actually see. No `Article` schema on guide
  pages: this project has no real author, tracked publish date, or
  photo to report truthfully, and schema.org/Google's guidance treats
  those as expected `Article` fields, so the honest choice was to omit
  it rather than fabricate them.

## The five guide pages

Each has: a specific title, an introduction that directly answers the
question, a plain-language explanation, at least one independently
checked worked example, a formula where it helps, an assumptions and
limitations list, a visible "Educational disclaimer" section, and
contextual links to the relevant calculator(s) and to the methodology
page. All five render their full text server-side (verified with
JavaScript disabled in the browser) and use no decorative or stock
imagery.

Independently derived worked examples (via a separate script, not by
calling the site's own calculation code):

- **Compound interest explained**: $5,000 at 5% nominal, no contribution,
  120 months → final balance $8,235.05 ($3,235.05 interest), contrasted
  with $2,500 simple interest over the same period.
- **How to calculate a savings goal**: $2,000 starting, $20,000 target,
  60 months, 4% nominal → required monthly contribution $264.83
  (verified by re-running it forward to land on exactly $20,000.00).
- **How extra loan payments work**: $15,000 at 7%, $300 required payment
  → baseline 60 months / $2,786.51 interest; with $100 extra → 43 months
  / $1,977.16 interest; 17 months and $809.35 saved.
- **Nominal interest rate vs APY**: $10,000 over 12 months at "6%" →
  $10,616.78 under the nominal interpretation vs. exactly $10,600.00
  under the APY interpretation ($16.78 difference); a 6% nominal rate
  compounded monthly is equivalent to a 6.1678% APY.
- **Inflation and buying power**: $50,000 in 20 years at 3% annual
  inflation → estimated buying power $27,683.79 today (contrasted with
  $37,204.70 at a 10-year horizon under the same assumption).
